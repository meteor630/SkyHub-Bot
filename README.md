# Discord-бот SkyHub Aviation

Production-ready плагинный Discord-бот для сообщества **SkyHub Aviation**
(авиасимуляторы, пилоты, диспетчеры, любители авиации). Бот спроектирован
как долгоживущая платформа, а не одноразовый скрипт: ядро не нужно менять,
чтобы добавить новую функцию, плагины перезагружаются "на лету" без
остановки процесса, и падение одного плагина никогда не роняет остальных.

```
Discord  <-->  SkyHubBot (discord.py)
                 │
                 ├── PluginManager  ──загружает/перезагружает──>  plugins/*
                 │                                                   │
                 ├── EventBus  <───────публикация/подписка───────────┘
                 │
                 ├── PermissionService, ErrorHandler, I18n, TTLCache
                 │
                 └── Database (SQLAlchemy async) ──> PostgreSQL
```

## Документация

Полная документация разбита на три файла:

- **[docs/COMMANDS.md](docs/COMMANDS.md)** -- все команды бота: настройка
  сервера (`/setup`), голосовые каналы, радио, модерация, тикеты,
  авиапрофиль, бортжурнал, погода, XP и всё остальное.
- **[docs/DEPLOYMENT.md](docs/DEPLOYMENT.md)** -- установка на сервер с
  нуля (Docker и вручную), настройка бота в Discord Developer Portal,
  **что можно обновлять без перезапуска бота** (плейлист радио,
  настройки `/setup`, перезагрузка одного плагина) и что требует
  полного перезапуска, работа с миграциями базы данных, консоль
  управления, частые проблемы.
- **[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)** -- архитектура,
  структура проекта, как писать новые плагины, как устроена горячая
  перезагрузка, тестирование, и результаты аудита безопасности.

## Возможности

- Модерация (ban/kick/timeout/warn) + захват прямых действий через
  audit-log Discord, с защитой от применения санкций к участнику с
  равным/более высоким уровнем доступа
- Логи удалённых/изменённых сообщений, входов/выходов участников
- Временные приватные голосовые комнаты с управлением владельцем
  (обычные и быстрые -- "на 2"/"на 4" места)
- Непрерывное радио из загруженных треков с обложками, громкостью и
  очередью
- Тикеты поддержки, единый таймлайн участника (`/audit`)
- Авиационный профиль участника, бортжурнал, METAR/TAF, совместные
  вылеты сообщества, XP/уровни/репутация, сводная статистика сервера
- Вся настройка -- прямо из Discord (`/setup ...`), без правки файлов
  на сервере

## Быстрый старт

```bash
git clone <адрес-вашего-репозитория> skyhub-bot
cd skyhub-bot
cp .env.example .env   # впишите DISCORD_TOKEN
docker compose up --build -d
docker compose exec bot alembic upgrade head
```

Подробности, включая получение токена и настройку интентов в Discord
Developer Portal -- в [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md).

> **Про имя пакета:** в ТЗ предлагался пакет верхнего уровня `logging/`.
> Это перекрыло бы стандартный модуль Python `logging` для каждого
> `import logging`, как только корень проекта попадёт в `sys.path`,
> поэтому здесь для той же задачи используется `logging_config/`.
